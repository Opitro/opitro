faq:
  - question: Will this create real stereo?
    answer: No, and it would be dishonest to promise otherwise. The same signal is laid across two channels — there's no width or space to recover, because none was in the original recording. This tool is for compatibility, not for sound.
  - question: So what is it actually for?
    answer: Some video editors, players and devices only accept two-channel files, or will otherwise send a mono track to just one speaker. Re-saving as stereo fixes that without changing anything you can hear.
  - question: What do the pan-left and pan-right modes do?
    answer: They send the audio entirely to one side and leave the other silent. That's useful when you're assembling multitrack material and want two speakers on separate channels so you can treat them separately later.
  - question: What if the file is already stereo?
    answer: The tool warns you, right under the setting. In that case only the left channel is taken and copied to both sides, so the right channel is lost. For a stereo file you don't need this tool.
  - question: Does the file double in size?
    answer: In WAV, yes — the second channel takes the same space again. In MP3 the increase is much smaller, because the codec sees two identical channels and doesn't store them twice in full.
  - question: Can I hear it before downloading?
    answer: Yes, the play button plays the result. In duplicate mode it sounds identical to the original — which is exactly right.

Load a file, pick a mode and download. There's only one setting, and for most purposes the default — duplicate — is the one you want.

## What it's good for

- **Voice-over for a video project** where the track has to be two-channel
- **An old mono recording** a player insists on sending to one speaker only
- **Prepping for an edit** — putting two speakers on the left and right channels
- **Platform requirements**, when whatever you're uploading to only takes stereo

Straight about the main point: this will not make the file sound wider. If you want an actual sense of space, that comes from processing rather than from duplicating a channel — see [reverb and echo](/en/reverb-echo).

Going the other way: [stereo to mono](/en/stereo-to-mono).
