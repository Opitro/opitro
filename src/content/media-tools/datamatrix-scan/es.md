Apunte con la cámara al código o elija una imagen: el contenido aparece como texto y se puede copiar.

## Qué es este código

Data Matrix es un cuadrado de puntos pequeños, normalmente del tamaño de una uña. Se elige donde hay poco sitio para un código: en la caja de un medicamento, en una pieza diminuta, en una placa. Aun así guarda bastante más que un código de barras rayado.

## Qué sacamos de él

Mostramos el contenido entero y tal cual. Si el código sigue las reglas GS1, además lo ordenamos por campos: número de artículo, lote, fechas. Las fechas se muestran de forma legible, no como seis cifras seguidas.

El nombre del producto no está en el código, y no vamos a inventarlo.
