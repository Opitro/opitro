faq:
  - question: Why would I want mono instead of stereo?
    answer: Mono is standard for phone systems, some radio/broadcast formats, and voice recordings where a stereo spread doesn't add anything — it also roughly halves the file size at the same bitrate.
  - question: Will this change how the file sounds on normal speakers?
    answer: Both channels get mixed together, so anything that was panned left or right ends up centered — for most spoken-word or mono-source recordings this is unnoticeable.
