Point the camera at the code or choose a picture — the contents appear as text you can copy.

## What this code is

Aztec is a square with a bullseye in the middle. It needs no empty margin around it, so it takes less room than a QR code — which is why tickets use it: European rail, airline, electronic travel passes.

## What we show

The string written by the carrier, as it is. We do not decode it per railway format: a guessed breakdown is worse than honest text.

Neither the picture nor the result goes anywhere — and a ticket usually carries your name too.
