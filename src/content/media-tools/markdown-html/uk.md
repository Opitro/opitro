Вставте текст — переклад і живий показ з’являться одразу. Перемикання напрямку підставляє попередній результат у поле введення: так зручно перевірити зворотний переклад.

## Почніть із напрямку

Markdown → HTML потрібен, коли текст написано по-людськи, а вставити його треба в шаблон, лист або систему, яка розуміє лише теги. HTML → Markdown — зворотна задача: перенести готову сторінку в README, у базу знань або в редактор, де теги недоречні. Другий напрямок важчий, і результат майже завжди потребує правки руками.

## Очистку краще не вимикати

Позначка стоїть не для краси. Текст із чужого редактора несе верстку цього редактора: порожні обгортки, невидимі стилі, посилання на чужі картинки. У Markdown усе це переїжджає сирим HTML і лишається там назавжди. Вимикати очистку варто лише в одному випадку: коли ви точно знаєте, що у вихідному тексті немає нічого зайвого, і хочете зберегти теги як є.

## Перевіряйте за показом, а не за кодом

Дивитися на рядки з тегами втомливо й марно: пропущений список чи з’їхалий заголовок у коді майже непомітні, а в показі видно одразу. Показ іде справжнім браузером у замкненій рамці, тому виглядає рівно так, як виглядатиме в читача.
