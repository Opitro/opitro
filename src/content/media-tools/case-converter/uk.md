## П’ять стилів

- **camelCase** — `userFirstName`, прийнято в JavaScript
- **PascalCase** — `UserFirstName`, для класів і типів
- **snake_case** — `user_first_name`, прийнято в Python і в базах даних
- **kebab-case** — `user-first-name`, для класів CSS і адрес сторінок
- **UPPER_CASE** — `USER_FIRST_NAME`, для сталих значень

## Три місця, де ламається наївне правило

**Абревіатури.** За правилом «велика починає слово» `parseHTTPResponse` стало б `parse_h_t_t_p_response`. Насправді виходить `parse_http_response`.

**Цифри.** `user2Name` — це `user2` і `Name`. Виходить `user2_name`.

**Підкреслення по краях.** У Python `__init__` та `init` — різні імена.

## Список повертається готовим до вставки

Відступи та хвостові коми зберігаються: рядок `  userName,` стане `  user_name,`.
