faq:
  - question: How much smaller does the file get?
    answer: Roughly proportional to the bitrate drop — going from 192 to 96 kbps cuts the file size close to half.
  - question: Will lowering the bitrate hurt the sound quality?
    answer: Yes, some — 96 kbps is fine for spoken word, but for music, going much below 128 kbps starts to noticeably lose detail.

Pick a target bitrate and hit Process — the smaller file downloads as an MP3. Useful when a file is too large to email, attach, or upload somewhere with a size limit.
