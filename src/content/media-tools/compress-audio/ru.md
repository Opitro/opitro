title: Сжать аудио онлайн бесплатно — уменьшить размер файла
h1: Сжать аудиофайл
description: Уменьшите размер аудиофайла, перекодировав его с меньшим битрейтом. Бесплатно, прямо в браузере, без регистрации.
faq:
  - question: Насколько уменьшится файл?
    answer: Примерно пропорционально снижению битрейта — переход со 192 на 96 kbps уменьшает файл почти вдвое.
  - question: Снижение битрейта испортит качество звука?
    answer: Немного — 96 kbps вполне подходит для речи, а для музыки снижение сильно ниже 128 kbps уже заметно теряет детали.
---

Выберите целевой битрейт, нажмите "Обработать" — уменьшенный файл скачается в MP3. Пригодится, когда файл слишком большой для письма, вложения или загрузки туда, где есть ограничение по размеру.
