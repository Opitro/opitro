faq:
  - question: Does the order I add files matter?
    answer: Yes — files play in the order you added them, one after another. If you need a different order, re-add them in the order you want.
  - question: Can I merge different formats together, like an MP3 and a WAV?
    answer: Yes, the tool re-encodes everything to a consistent format before joining, so mixed input formats work fine.

Add each file one at a time, then hit Process — they get joined back-to-back into one MP3. Handy for stitching together a podcast recorded in separate takes, combining voice memos, or putting several short clips into one file.
