Перетащите файл в рамку или выберите на диске. Результат появится сразу, вместе с честным подсчётом веса.

## Base64 делает файл тяжелее на треть

Три байта превращаются в четыре знака — это свойство способа. Мы показываем исходный вес, итоговый и прирост, чтобы решение принималось с открытыми глазами.

## Встраивать выгодно только мелочь

Маленький значок или простой SVG — да. Крупную картинку — нет: она станет тяжелее, потеряет отдельное кеширование и, если попадёт в CSS, задержит отрисовку.

## Data URL и чистый Base64 — разные вещи

В `src` картинки и в `url()` стилей идёт Data URL с приставкой `data:image/png;base64,`. Чистые данные там бесполезны.
