Вставьте код и нажмите кнопку. Ряд наверху уводит к соседям: минификатору HTML и минификатору CSS.

## Почему здесь настоящий разбор

Для разметки и стилей мы написали свой разбор — там неверное сжатие видно глазом. Для JavaScript так делать нельзя. Сокращение имён требует знать область видимости каждой переменной: какая объявлена здесь, а какая пришла снаружи. Без дерева отличить одно от другого невозможно, и переименование ломает код молча — не при сжатии, а потом, у пользователя.

Поэтому здесь работает Terser, тот же разбор, что стоит в сборщиках настоящих проектов. Он подгружается только по нажатию кнопки — 170 КБ, один раз за посещение.

## Что вы получите

На примере из задания видно оба рода работы сразу:

```
function calculateTotal(price, quantity) {
    // Налог
    let taxRate = 0.2;
    return (price * quantity) * (1 + taxRate);
}
```

превращается в

```
function calculateTotal(t,a){return t*a*1.2}
```

Убраны пробелы и комментарий, сокращены имена, а заодно свёрнута арифметика, которую можно посчитать заранее: `1 + 0.2` стало `1.2`, и промежуточная переменная исчезла за ненадобностью. Имя самой функции осталось: она объявлена наружу, и переименовать её значило бы оборвать связь с тем, кто её вызывает.

## Когда сокращение имён лучше выключить

Если код смотрит на собственные имена: обращается через `eval`, собирает имя из строки или сверяет `fn.name`. Тогда снимите галочку — вес выйдет больше, зато поведение не изменится.
