## Чому тут справжній розбір

Для розмітки та стилів ми написали свій розбір — там невірне стиснення видно оком. Для JavaScript так робити не можна. Скорочення імен вимагає знати область видимості кожної змінної: яка оголошена тут, а яка прийшла ззовні. Без дерева відрізнити одне від іншого неможливо, і перейменування ламає код мовчки — не при стисненні, а потім, у користувача.

Тому тут працює Terser, той самий розбір, що стоїть у збирачах справжніх проєктів. Він підтягується лише за натисканням кнопки — 170 КБ, один раз за відвідування.

## Що ви отримаєте

На прикладі із завдання видно обидва роди роботи одразу:

```
function calculateTotal(price, quantity) {
    // Податок
    let taxRate = 0.2;
    return (price * quantity) * (1 + taxRate);
}
```

перетворюється на

```
function calculateTotal(t,a){return t*a*1.2}
```

Прибрано пробіли й коментар, скорочено імена, а заразом згорнуто арифметику, яку можна порахувати наперед: `1 + 0.2` стало `1.2`, і проміжна змінна зникла за непотрібністю. Імʼя самої функції лишилося: вона оголошена назовні, і перейменувати її означало б обірвати звʼязок із тим, хто її викликає.

## Коли скорочення імен краще вимкнути

Якщо код дивиться на власні імена: звертається через `eval`, збирає імʼя з рядка або звіряє `fn.name`. Тоді зніміть позначку — вага вийде більша, зате поведінка не зміниться.
